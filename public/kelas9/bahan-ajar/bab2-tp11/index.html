2Pseudocode Itu Apa Sih?

Rancangan algoritma yang bisa dibaca manusia, tapi belum bisa dijalankan komputer.

Pseudocode memakai bahasa mirip sehari-hari, ditambah kata kunci ala pemrograman seperti IF, WHILE, dan CETAK (huruf kapital). Ia adalah perantara antara bahasa manusia dan bahasa pemrograman.

5Kamus Translasi

Klik gambar untuk memperbesar. Ini andalanmu saat menerjemahkan.

Ingat!input() di Python selalu menghasilkan teks. Untuk bilangan, bungkus dengan int() atau float().
Trik ScratchScratch nggak punya tanda ≥. total ≥ 20000 ditulis not <total < 20000>. Di Python, THEN dan ENDIF diganti titik dua dan indentasi.
Awas jebakan!WHILE jalan selama kondisi benar, sedangkan repeat until berhenti kalau kondisi benar. Balik kondisinya dengan not. Dan FOR i ← 1 TO n jadi range(1, n + 1).
RETURN vs CETAKRETURN menyerahkan nilai ke pemanggil, CETAK hanya menampilkan. Scratch nggak punya RETURN: simpan hasil di variabel.

12Rangkuman

  • Pseudocode = rancangan algoritma mirip bahasa manusia, belum bisa dijalankan.
  • Translasi = menerjemahkan ke blok atau teks dengan makna sama.
  • Empat langkah: BACA → PETAKAN → GANTI → UJI.
  • ← jadi =; BACA jadi int(input()); CETAK jadi print().
  • IF di Python: titik dua + indentasi. WHILE di Scratch: repeat until not.
  • FOR jadi range(1, n + 1).
  • RETURN menyerahkan nilai, CETAK hanya menampilkan.
  • Selalu uji, terutama nilai batas.

Tantangan Bintang

Kantin hanya melayani maksimal 5 antrian. Jika n > 5, cetak "Antrian penuh". Jika tidak, cetak nomor antrian 1 sampai n. Tulis pseudocode-nya, terjemahkan ke Scratch dan Python, lalu uji dengan n = 3 dan n = 8.

Lihat kunci
n = int(input("Banyak pembeli: ")) if n > 5: print("Antrian penuh") else: for i in range(1, n + 1): print("Antrian ke-" + str(i))
