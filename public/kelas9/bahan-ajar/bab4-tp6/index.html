Delapan kasus Tim Tanggap Siber

Buka satu kasus dan coba tebak ancamannya sebelum membaca materi di bawah.

K1 Misteri File Nilai Terkunci

Senin pagi, Bu Rina di ruang TU membuka lampiran email berjudul Rekap_Nilai_Final.zip dari pengirim yang tidak ia kenal. Beberapa menit kemudian seluruh file di komputernya berubah menjadi berekstensi .locked. Di layar muncul pesan: 'Semua file Anda terkunci. Kirim tebusan dalam 48 jam atau data hilang selamanya.' Cadangan terakhir ada di flashdisk yang selalu tercolok di komputer itu.

K2 Beasiswa Kilat

Dito, siswa kelas IX, menerima pesan WhatsApp dari nomor tak dikenal: 'SELAMAT! Kamu terpilih menerima BANTUAN PENDIDIKAN Rp1.500.000. Klik http://bantuan-siswa-resmi.xyz/login dan isi NIS serta kata sandi akun belajar. Berlaku 1 jam!' Karena takut hangus, Dito langsung mengisinya. Besoknya akun belajarnya login dari perangkat lain dan mengirim pesan aneh ke teman-temannya.

K3 Game Gratis Rasa Jebakan

Raka mengunduh Game_Mod_Unlimited.apk dari situs tidak resmi karena ingin bermain gratis tanpa batas. Game berjalan normal. Namun beberapa hari kemudian HP-nya cepat panas, kuota habis tiba-tiba, muncul aplikasi yang tidak pernah ia pasang, dan akun gamenya dibobol.

K4 Flashdisk Keliling

Sinta mencetak tugas di tempat fotokopi, lalu membawa flashdisknya ke Lab Informatika. Di lab, seluruh folder di flashdisk berubah menjadi pintasan (shortcut) dan tidak bisa dibuka. Setelah flashdisk dicolok ke dua komputer lab, beberapa file di komputer itu ikut bermasalah dan ada file program aneh bernama tugas.exe.

K5 Lab Melambat Serentak

Pagi hari, 20 komputer Lab Informatika tiba-tiba sangat lambat. Penyimpanan cepat penuh karena muncul ribuan file acak berukuran kecil. Anehnya, tidak ada satu pun siswa yang membuka file mencurigakan. Teknisi menemukan satu komputer terinfeksi yang terhubung ke jaringan lab dan mengirim email massal ke banyak alamat.

K6 Akun Diambil Alih

Wulan login ke email, media sosial, dan game dari komputer di tempat rental internet. Beberapa hari kemudian ketiga akunnya dibobol. Wulan memakai kata sandi yang sama untuk semua akun, yaitu wulan2010 (namanya + tahun lahir). Sebelumnya, ia juga mendapat kabar bahwa salah satu situs game yang ia ikuti pernah mengalami kebocoran data.

K7 Wi-Fi Gratis di Kafe

Ardi nongkrong di kafe dan melihat Wi-Fi bernama Free_WiFi_Kafe tanpa kata sandi. Wi-Fi resmi kafe sebenarnya bernama 'Kafe Senja'. Setelah tersambung, muncul halaman yang meminta Ardi login ulang akun media sosialnya. Tidak lama kemudian akunnya diretas dan beberapa pesan ke temannya diubah.

K8 Situs Sekolah Tak Bisa Dibuka

Saat pengumuman penting, situs/aplikasi sekolah tidak dapat diakses selama tiga jam. Catatan server menunjukkan ribuan permintaan per detik dari banyak alamat IP yang tidak dikenal. Tidak ada data yang hilang atau dicuri, tetapi guru, siswa, dan orang tua tidak bisa membuka layanan.

2Peta ancaman digital

Serangan siber adalah pemanfaatan teknologi untuk mencuri data, merusak perangkat, atau mengganggu layanan.

Dua kategori malware

Tidak merusak: mengganggu atau mencuri info (adware, spyware). Tanda perangkat sudah bobol.

Merusak: menghapus, mengubah, merusak file, mengambil alih perangkat, atau memeras korban.

3Kenalan dengan malware

Pilih jenis malware di bawah untuk melihat cara kerja, ciri, dan cara menanganinya.

🧬 Virus

Kode yang menempel pada file atau program dan memperbanyak diri. Biasanya aktif karena kamu menjalankan file yang terinfeksi.

Ciri-ciri

  • File berubah jadi pintasan atau rusak
  • Muncul file .exe yang tidak dikenal
  • Komputer melambat
Cara menangani: Pindai flashdisk sebelum dibuka, jalankan antivirus, jangan jalankan file .exe asing.

🪱 Worm

Menggandakan diri dan menyebar otomatis lewat jaringan atau email, tanpa perlu diklik.

Ciri-ciri

  • Banyak komputer lambat bersamaan
  • File acak bertambah sendiri
  • Penyimpanan cepat penuh
Cara menangani: Isolasi komputer terinfeksi, antivirus, update sistem, aktifkan firewall.

🔐 Ransomware

Mengenkripsi datamu lalu meminta tebusan agar bisa dibuka lagi.

Ciri-ciri

  • File berekstensi aneh (.locked)
  • Pesan tebusan + hitung mundur
  • File tidak bisa dibuka
Cara menangani: Putus jaringan, jangan bayar, pulihkan dari backup, lapor.

🐴 Trojan Horse

Menyamar sebagai program berguna padahal menyimpan fungsi jahat; menyerang langsung dari dalam dan sering mengunduh malware lain.

Ciri-ciri

  • Aplikasi dari sumber tak resmi (APK mod)
  • HP panas, kuota habis
  • Muncul aplikasi asing
Cara menangani: Unduh dari sumber resmi, hindari software bajakan, baca izin aplikasi.

🚪 Backdoor

Pintu belakang tersembunyi yang memberi akses jarak jauh ke sistem tanpa sepengetahuan pemilik.

Ciri-ciri

  • Pengaturan berubah sendiri
  • Ada koneksi keluar tak dikenal
  • Contoh IoT: CCTV bisa dilihat orang asing
Cara menangani: Ganti sandi bawaan, firewall dan update aktif, hapus program tak dikenal.

🕵️ Spyware & Keylogger

Memata-matai pengguna dan mencuri nama pengguna serta kata sandi. Keylogger merekam setiap ketikan.

Ciri-ciri

  • Aktivitas akun yang tidak dikenal
  • Perangkat melambat
  • Akun dibobol walau sandi “rahasia”
Cara menangani: Antivirus aktif, hindari komputer umum, aktifkan 2FA.

4Serangan siber lainnya

Tidak semua serangan adalah malware. Buka tiap kartu.

🎣 Phishing

Pesan atau situs palsu untuk memancing data sensitif. Serangan jalan setelah korban merespons.

Pertahanan: Berhenti, Periksa, Tanya. Jangan isi data lewat tautan kiriman. Terlanjur? Ganti sandi dan aktifkan 2FA.
🌊 DDoS

Membanjiri server dengan permintaan dari banyak sumber sampai layanan lumpuh. Tidak mencuri data, tetapi merugikan.

Pertahanan: Firewall, pembatasan permintaan, layanan penyaring lalu lintas dari penyedia hosting.
🕸️ Man in the Middle

Penyerang menempatkan diri di tengah komunikasi, biasanya di Wi-Fi publik, lalu menyadap atau mengubah data.

Pertahanan: Gunakan VPN, tanya nama Wi-Fi resmi, hindari login dan transaksi penting di jaringan publik.
🔑 Password Attack

Menebak atau mencuri kata sandi: brute force, dictionary, credential stuffing, dan keylogger.

Pertahanan: Sandi panjang dan unik untuk tiap akun, jangan pakai nama/tanggal lahir, aktifkan 2FA.

Trik baca tautan

Cari tanda //, lalu baca sampai garis miring pertama dari kanan. Dua bagian terakhir adalah domain sebenarnya. Nama sekolah di depan hanya umpan. Gembok https bukan jaminan situs asli.
