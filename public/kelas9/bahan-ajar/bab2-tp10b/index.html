8. Kuis Mandiri (10 soal)

Rangkuman

  • Loop di flowchart = garis alir yang kembali ke pengecekan.
  • Empat bagian: inisialisasi, kondisi, badan, pembaruan.
  • for untuk jumlah putaran diketahui; while untuk berhenti karena data (sentinel).
  • Flowchart: kondisi keluar; while: kondisi lanjut (dibalik).
  • Akumulator: nilai awal sebelum loop, diperbarui di dalam loop.
  • Bug loop: tanpa henti, off-by-one, akumulator direset, bagi dengan nol.
Tugas mini (Iuran Kas): baca iuran berulang sampai 0, cetak total, banyak penyetor, dan iuran terbesar. Uji 2000, 5000, 1000, 0 → 8000, 3, 5000.
