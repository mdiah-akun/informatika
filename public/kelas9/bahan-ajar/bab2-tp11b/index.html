11Rangkuman

  • Sentinel: penanda selesai, bukan data. WHILE x <> 0 → repeat until <x = 0> / while x != 0:.
  • Akumulator dan pencacah: nilai awal SEBELUM perulangan.
  • ELSE IF: Scratch if di dalam else; Python elif. Syarat paling sempit dulu.
  • DIV → // / floor of. MOD → % / mod. / = desimal.
  • Daftar: pseudocode 1, Python 0. append, len, in.
  • Dekomposisi proyek menjadi fungsi.
  • Uji nilai batas dan kasus kosong.
