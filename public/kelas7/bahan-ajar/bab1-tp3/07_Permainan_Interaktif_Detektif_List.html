NODE — satu kartu/elemen dalam list, berisi NILAI dan PENUNJUK.  ·  HEAD — node pertama (nilainya tidak pernah jadi penunjuk kartu lain).  ·  POINTER (penunjuk) — menunjukkan node berikutnya dalam rangkaian.  ·  TAIL — node terakhir, penunjuknya ∅ (kosong).  ·  TRAVERSAL — menelusuri list dari head sampai tail, satu per satu.
